    Используемые технические средства

    Технические средства персонального компьютера пользователя должны иметь следующую минимальную конфигурацию:

    • процессор Intel Core i5-2500 3,3 ГГц;
    • оперативная память 8 ГБ;
    • свободное место на жестких дисках 10 ГБ.

    Рекомендуется использовать монитор не менее 17", клавиатуру и мышь.

    Программное обеспечение, необходимое для функционирования программы

    На персональный компьютер пользователя должен быть установлен веб-браузер Яндекс.Браузер с расширением КриптоПро ЭЦП Browser plug-in. Документация по установке расширения находится на сайте производителя плагина (https://docs.cryptopro.ru/cades/plugin).

    Требования к персоналу

    Пользователь должен обладать практическими навыками работы с персональным компьютером, с файловой системой компьютера, веб-браузером, электронной почтой, пакетом офисных программ.

    Климатические условия эксплуатации

    Климатические условия эксплуатации, при которых должны обеспечиваться заданные характеристики, должны удовлетворять требованиям, предъявляемым к техническим средствам в соответствии с указаниями производителя технических средств.
