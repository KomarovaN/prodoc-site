# Запуск и авторизация

Для запуска программы необходимо открыть веб-браузер, в адресной строке ввести _https://passper.ru_.

В веб-браузере откроется главная страница ЦП ПП «ПАСПЕР». Для авторизации и входа в Систему необходимо нажать ссылку «Войти» (Рисунок 1).

![Image](/sign-in/AW0W38M7EBPT_134611_2.png)

Рисунок - Ссылка «Войти» на главной странице.

На странице веб-браузера откроется окно авторизации, представленное на рисунке (Рисунок 2).

![Image](/sign-in/AW0W38M7EBPT_134611_3.png)

Рисунок - Окно входа.

Для авторизации следует ввести логин и пароль в соответствующие поля ввода и нажать кнопку «Войти».

Для регистрации пользователя в Системе требуется ввести адрес электронной почты и нажать кнопку «Зарегистрироваться».

Логин и пароль предоставляются администратором Системы на адрес электронной почты, предоставленный пользователем при регистрации.


# Общие положения

Пользовательский интерфейс выполнен с применением графических и визуальных элементов: окон, полей, кнопок, меню, ссылок и др. Правила работы с данными элементами не отличаются от общепринятых правил, например, в ОС Windows и в веб-браузерах.

При описании работы с пользовательским интерфейсом программы фраза «нажать (щёлкнуть) кнопку (значок, ссылку)» или «выбрать пункт меню (надпись)» означает, что следует навести указатель мыши на указанную кнопку или пункт меню и щёлкнуть левой кнопкой мыши.

Для ввода значения из выпадающего списка необходимо в поле ввода начать вводить значение или часть значения из выпадающего списка или нажать значок ▼или ![Image](/sign-in/AW0W38M7EBPT_134611_1.png){.no-frame}, расположенный справа от поля ввода. Далее выбрать указателем требуемое значение в списке, щёлкнуть левой кнопкой мыши. Список исчезнет, а выбранное значение появится в поле ввода.

Некоторые функции, описанные в руководстве, могут быть недоступны пользователю. Это определяется правами доступа, установленными для конкретного пользователя.
