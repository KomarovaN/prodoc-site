Инструкция предназначена для сотрудников ФБУ «Росавтотранс», ответственных за ведение реестров межрегиональных и международных маршрутов регулярных перевозок и реестра остановочных пунктов по межрегиональным и международным маршрутам регулярных перевозок.

Инструкция содержит описание действий по формированию и отправке исходящих писем при установлении/изменении межрегиональных и международных маршрутов регулярных перевозок и регистрации/изменении остановочных пунктов по межрегиональным маршрутам регулярных перевозок в программном комплексе «Цифровая платформа пассажирских перевозок «ПАСПЕР» (далее по тексту – ЦП ПП «ПАСПЕР» или Система).


# Запрос в Ространснадзор и регистрация ответа

В ЛК менеджера по межрегиональным перевозкам / менеджера по международным перевозкам перейти в раздел «Письма», открыть вкладку «Исходящие» / «Исходящие по международным» и нажать на ссылку «+Добавить» (Рисунок 1).

![Image](NQRD7ZEH1E5K_142230_1.png)

Рисунок - Ссылка «+Добавить» для создания исходящего письма

В открывшемся окне (Рисунок 2):

-   в поле «Выберите тип письма» выбрать из выпадающего списка значение «Запрос в Ространснадзор по штрафам в области транспорта»,
-   в появившемся поле «Заявления на Маршрут» выбрать из предлагаемого списка один или несколько номеров;
-   нажать кнопку «Создать».

![Image](NQRD7ZEH1E5K_142230_2.png)

Рисунок – Создание запроса в Ространснадзор

На странице откроется новая карточка письма в статусе «Новое» (Рисунок 3), номер и дата исходящего письма присваиваются автоматически.

-   нажать кнопку «Создать процесс» (Рисунок 4);

# Согласование с УИО субъектов РФ

В ЛК менеджера по межрегиональным перевозкам / менеджера по международным перевозкам перейти в раздел «Письма», открыть вкладку «Исходящие», и нажать на ссылку «+Добавить» (см. Рисунок 1).

В открывшемся окне (Рисунок 19):

-   в поле «Выберите тип письма» выбрать из выпадающего списка значение «Извещение УИО субъекта РФ»,
-   в появившемся поле «Регион» выбрать субъект РФ, с которым требуется согласовать заявленный маршрут(-ы);
-   в появившемся поле «Заявления на Маршрут» выбрать из предлагаемого списка один или несколько номер(-ов) заявления(-й) на маршрут, которые требуется согласовать с выбранным субъектом РФ;
-   нажать кнопку «Создать».

![Image](NQRD7ZEH1E5K_142230_21.png)

Рисунок – Создание извещения УИО субъекта РФ

Для отправки новой карточки письма на согласование и подписание повторить действия п. 1.1.4.

Для каждого субъекта РФ, по территории которого проходит маршрут, повторить действия п.п. 1.2.1 - 1.2.3.

После получения входящего письма с ответом УИО субъекта РФ, для регистрации ответа в карточке исходящего письма выполнить действия, аналогичные для регистрации ответа на исходящее письмо типа «Запрос в Ространснадзор по штрафам в области транспорта» (п. 1.1.7).

После регистрации входящего письма с ответом УИО субъекта РФ или, если ответ не получен, то по истечение срока получения ответа (30 дней):

-   в карточке письма в блоке «Заявление на маршруты» нажать на значок ![Image](NQRD7ZEH1E5K_142230_22.png) (см. Рисунок 14);
-   в открывшемся окне в зависимости от полученного ответа выбрать одно из значений (Рисунок 20):

«В установленный срок ответ не получен» - если ответ не получен по истечение срока получения ответа;

«Основания для отказа отсутствуют» - заявление согласовано субъектом РФ;

«Причины для отказа» - заявление не согласовано, установить отметки для пунктов заявления, ставших причиной отказа;

-   нажать кнопку «Сохранить»;

![Image](NQRD7ZEH1E5K_142230_23.png)

Рисунок - Фиксация ответа УИО субъекта РФ в исходящем письме

-   карточке исходящего письма присваивается статус «Зарегистрирован ответ» (Рисунок 21).

![Image](NQRD7ZEH1E5K_142230_24.png)

Рисунок - Карточка исходящего письма типа «Извещение УИО субъекта РФ» в статусе «Зарегистрирован ответ»

-   в карточке заявления на вкладке «Процессы» отображается информация о согласовании с УИО субъектов РФ с указанием реквизитов исходящих писем и статуса ответа (Рисунок 22).

![Image](NQRD7ZEH1E5K_142230_25.png)

Рисунок - Сведения о согласовании с УИО субъектов РФ в карточке заявления на вкладке «Процесс»

В карточке заявления по маршруту на вкладке «Процесс» в блоке «Извещение УИО субъекта РФ» столбец «Регион» автоматически предзаполняется названиями субъектов РФ, через которые проходят ОП из блока «Расписание» вкладки «Инфо». ![Image](NQRD7ZEH1E5K_142230_27.png)

Рисунок - Отправка извещений в УИО субъекта РФ

-   в открывшемся окне «Добавить регионы» в поле «Регионы» выбрать из выпадающего списка субъекты РФ, по территории которых проходит заявленный маршрут, и нажать кнопку «Добавить» (Рисунок 25);

# Маршруты. Подготовка и направление проектов решений Минтранса России

Проект решения Минтранса России по заявлению об установлении/изменении маршрута может быть как положительным, так и отрицательным в соответствии с результатами рассмотрения заявления. Для каждого решения предусмотрен тип исходящего письма:

-   «Проект решения Минтранс России положительный»,
-   «Проект решения Минтранс России отрицательный».

В ЛК менеджера по межрегиональным перевозкам / менеджера по международным перевозкам перейти в раздел «Письма», открыть вкладку «Исходящие», и нажать на ссылку «+Добавить» (см. Рисунок 1).

В открывшемся окне (Рисунок 31):

-   в поле «Выберите тип письма» выбрать из выпадающего списка значение «Проект решения Минтранс России положительный» или «Проект решения Минтранс России отрицательный»;
-   в появившемся поле «Заявления на Маршрут» выбрать из предлагаемого списка один или несколько номер(-ов) заявления(-й) на маршрут, по которым требуется принять решение;
-   нажать кнопку «Создать».

![Image](NQRD7ZEH1E5K_142230_35.png)

Рисунок – Создание проекта решения Минтранса России

Для отправки новой карточки письма на согласование и подписание повторить действия п. 1.1.4.

После отправки исходящего письма с проектом решения, в карточке заявления, по которому отправлен проект решения, на вкладке «Процессы» в блоке «Проект решения Минтранса» отображается информация об отправлении (Рисунок 32) с указанием реквизитов письма и даты отправки (дата отправки определяется в Системе датой нажатия кнопки «Подписать» или, если подписание и отправка исходящего письма осуществляется вне Системы, датой нажатия кнопки «Отправлено» (п. 1.7)).
